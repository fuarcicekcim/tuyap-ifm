# FUAR ÇİÇEKCİM

Fuar standları ve kurumsal etkinlikler için tek sayfalık, mobil uyumlu çiçekçi ve ürün kataloğu sitesi.

## Önizleme

`index.html` dosyasını tarayıcıda açın. Site statik HTML, CSS ve JavaScript ile hazırlanmıştır; derleme veya bağımlılık kurulumu gerekmez.
